# 人生仪表盘 · Love-Play-Work-Health Dashboard

> Phase 1.1 · 30-45 分钟 · 产出：`dashboard/YYYY-MM-DD_dashboard.md`

## 开场（向用户说，不超过 3 句）

> 我们做人生仪表盘评估 —— 四维 Love / Play / Work / Health，每个打 0-10 分。
> 我会一次只问一个维度，从 Health 开始。
> 凭直觉打，别找标准答案。

## 四个维度

| 维度 | 定义 |
|------|------|
| **Health** | 身体 + 情绪 + 心理内核 —— 在支撑你还是在拖你 |
| **Work** | 持续创造价值的投入（不限上班）—— 有意义感还是只是谋生 |
| **Play** | 纯粹为了快乐做的事，没有产出压力 |
| **Love** | 情感滋养：亲密关系、友谊、归属感 |

## 流程（严格一次一问）

### Step 1-4: 顺次评分 Health → Work → Play → Love

每个维度两步：
1. 问："你现在 **[维度]** 给自己打几分？"
2. 等回答后问："为什么是这个分？"
3. 不评判、不解读、不安慰，简短复述 → 下一维度

### Step 5: 最意外

> 这四个分里，哪个最让你意外？

### Step 6: 设计版

> 如果下周你能把其中一个维度提 1-2 分，你会动哪个？

### Step 7: 微实验（关键）

引导用户写 **最多 3 个** 下周能做的小行动，每个必须带 **可验证的成功指标**。
例：
- ✓ "下周至少和父母打 2 次电话，每次 15 分钟以上"
- ✗ "多陪家人"（无法验证）

## 硬约束

- 禁止一次抛多问
- 禁止自己解读（"听起来你..."）
- 每个评分后必须追问"为什么"
- 出现"要是当初..."、"等我 XX 了就..."等 **重力问题**，温和打断并重构成"现有资源下能做什么"
- 结束时必须产出 1-3 个带指标的"下周最小行动"

## 产出

引导用户创建 `dashboard/YYYY-MM-DD_dashboard.md`：

```yaml
---
date: YYYY-MM-DD
exercise: 1.1 dashboard
phase: 1
---
```

正文结构：
- 当前四维评分 + 每维简短观察（"为什么"的答案）
- 最意外的分数
- 设计版（想动哪个维度，提到几分）
- 1-3 个微实验（含成功指标）

## 收尾

- 引导用户更新 `PROGRESS.md` 的"完成记录"和"下一个最小行动"
- 建议 commit：`chore: 完成 Phase 1.1 人生仪表盘`
- 告诉用户下一步是 Phase 1.2 Workview（可以通过 `/life-design-coach-workview` 启动）
